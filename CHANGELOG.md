# Changelog

All notable changes to StaffForge will be documented in this file.

This project follows a simple versioning format:

- Major updates: large feature changes or architecture changes
- Minor updates: new features and improvements
- Patch updates: bug fixes, small improvements, and documentation changes

---

## [1.0.0] - Initial Public Release

### Added

- Staff application profile management
- Minecraft server application tracker
- Status tracking system
- Answer generator
- AI-style personalization scaffold
- Universal browser autofill extension
- Question mapping system
- Interview preparation tools
- Moderation CV export
- Analytics dashboard
- Gmail parsing scaffold
- Google Calendar reminder scaffold
- Supabase cloud sync scaffold
- JWT authentication scaffold
- Electron desktop wrapper
- Windows installer support
- GitHub documentation and repository templates

### Security

- Local-first data storage approach
- Manual review required before form submission
- No automatic application submission
- Anti-scam distribution notice
- Privacy-first README guidance

### Notes

This is the first public version of StaffForge. Some integrations are scaffolded and may require configuration before full production use.
